## Reporting a Vulnerability

**Please report security vulnerabilities via GitHub Security Advisories:**

1. Go to the [Security tab](https://github.com/Zaineb-Messaoudi/Esprit_5TWIN7_BuilDream/security/advisories/new)
2. Click "Report a vulnerability"
3. Fill in the details

**Or email:** security@solarshare.app (include "SECURITY" in subject)

**Response timeline:**
- **24 hours** - Acknowledgment of receipt
- **72 hours** - Initial assessment & severity classification
- **7 days** - Status update
- **30 days** - Fix released (critical/high) or scheduled (medium/low)

We will keep you informed throughout the process and credit you in the advisory (unless you prefer anonymity).
